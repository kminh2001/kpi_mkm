# KPI MKM - Quản lý Hiệu suất & Vận hành

Hệ thống quản lý hiệu suất công việc, chỉ số KPI và tối ưu hóa quy trình sản xuất.

## 🚀 Giới thiệu
Repository này lưu trữ mã nguồn và tài liệu phục vụ cho công tác quản lý, theo dõi KPI và cải tiến liên tục trong vận hành sản xuất.

## 📁 Cấu trúc thư mục
- `/assets`: Chứa hình ảnh, biểu đồ và tài nguyên giao diện.
- `/docs`: Tài liệu hướng dẫn quy trình vận hành chuẩn (SOP) và biểu mẫu đánh giá.
- `index.html`: Trang giao diện chính hiển thị trên GitHub Pages.
